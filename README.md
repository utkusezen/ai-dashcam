# ai-dashcam
 machine learning-driven traffic sign recognition and speed suggestion via mobile dashcam

 
## Installation Guide

### Prerequisites

- Python 3.10
- android smartphone
- devices in the same wireless network

---

### Run Backend

```bash
cd backend
pip install -r requirements.txt
python app.py
```

---

### Android App

Install ai-dashcam.apk on a android phone.
